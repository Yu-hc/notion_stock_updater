# Notion stock uptader

This is a notion auto updater for stanley stock project.


## Features

- **`auto_fill_stocks.py`**: Automatically fills in basic stock information into your Notion database.
- **`auto_connect_link.py`**: 
  1. Connects links from the daily logs database to the stock database (creates a new stock page if none exists).
  2. Converts TradingView snapshot websites into embedded images.
